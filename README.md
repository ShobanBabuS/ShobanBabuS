## 🚀 Featured Projects

### 1. 🔍 [PricePeek – Universal Cross-Platform Price Comparison Engine](https://github.com/ShobanBabuS/Price-Peek)
`Python 3.11+` · `FastAPI` · `React 18` · `Vite` · `JavaScript` · `SQLite`

A full-stack price intelligence and product comparison platform tailored for Indian e-commerce and quick-commerce marketplaces.

- **Query & URL Parsing:** Supports both natural-language search queries and direct product URLs across stores (Amazon, Flipkart, JioMart, Blinkit, Zepto, BigBasket, Croma, and Tata 1mg).
- **Strict Variant Separation:** Normalizes units (`1000ml` → `1L`, `500g` → `0.5kg`) and extracts exact storage, RAM, color, and pack variants to avoid false comparisons.
- **Location-Aware Best Price Routing:** Filters delivery availability by user pincode, calculates savings across competing platforms, and links directly to verified store checkouts.
- **Modular Connector Architecture & Testing:** Built around a plug-and-play store connector registry backed by an automated `pytest` suite.

### 2. 🏥 [Hospital Management System (Apex Health Care)](https://github.com/ShobanBabuS/Hospital-Management-System)
`Java 25` · `Spring Boot 4.1.3` · `Gradle 9.5.0` · `SQLite` · `HTML / CSS / JavaScript`

A full-stack healthcare operations portal with role-separated workflows for **Admins**, **Doctors**, and **Patients**, backed by Spring Data JPA and an embedded SQLite database.

- **Admin Portal:** Physician onboarding, specialization directory management, search/filtering, CSV roster export, and cascade slot cleanup.
- **Unified Auth & Patient Onboarding:** Automatic Patient/Doctor role routing with dedicated Patient registration and password-confirmation validation.
- **Doctor Scheduling & Digital Prescriptions:** 15-minute outpatient slot publishing (`9:00 AM`–`6:00 PM`), day-sheet printing, CSV schedule exports, and a **`Morning · Afternoon · Night` (`M A N`, e.g. `1 0 1`)** tablet prescription manager with `+` / `-` steppers.
- **Patient Booking & Slips:** Dynamic specialization/date/time filtering, conflict-free exclusive slot booking, printable appointment slips, and a live **My Prescriptions** view.

### 3. 🪨 [Shilpa-Kala Showcase](https://github.com/ShobanBabuS/Shilpa-Kala-Showcase)
`Kotlin` · `Android SDK (API 26–34)` · `Gradle Kotlin DSL` · `Firebase` · `HTML`

A dual-sided heritage marketplace Android application created to connect traditional stone and wood carvers (*Shilpis* from Shivarapatna) directly with art collectors, temple trusts, and buyers.

- **Buyer & Collector Experience:** Heritage splash onboarding, featured sculpture discovery, style/material gallery chips, verified artisan profiles, and bookmark saving.
- **Artisan / Seller Tools:** Dedicated seller dashboard with portfolio metrics, portfolio grid, and work-in-progress craft showcases.
- **Direct Enquiries & Localization:** One-tap WhatsApp buyer-artisan enquiry integration alongside **English** and **Kannada** string resources.
